# sc-to-mp4

## Command-Line Options

```text
usage: sc_to_mp4.py [-h] [--img IMG] [--mp3] [-o OUTPUT] [url]

Convert SoundCloud URLs to MP4 videos or MP3 audio

positional arguments:
  url                  SoundCloud track or playlist URL

options:
  -h, --help           Show this help message and exit
  --img IMG            Path to a custom image to use instead of the SoundCloud thumbnail
  --mp3                Download as MP3 audio only (skip MP4 video creation)
  -o, --output OUTPUT  Directory where downloads will be saved (default: 'downloads')
```
